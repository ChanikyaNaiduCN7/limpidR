# limpidR 0.1.0

- Initial research-software release candidate.
- Bundled LIMPID-India v1.0.0 example data model.
- Database structural validation and unit harmonization.
- Abundance, morphology, size and polymer summaries.
- Compositional closure, CLR transforms and Aitchison distance.
- Lognormal and Gamma abundance modelling.
- Leave-one-group-out cross-validation, defaulting to Lake_ID.
- Transparent risk components without hard-coded hazard weights.
- Relative hotspot classification and map visualizations.
- Explicit refusal of unsupported depth-profile inference.
